DMN · Operator interface

Contact reconsideration

A separate way to ask the instance to reconsider a block, including when a suspected attribution error has left everyone blocked. Your reasoning is part of the request. The instance may decline, defer or remain silent.

Operator access

Use the operator access key for this instance. It stays in this page's memory until you disconnect or reload.

Participants

Contact state is shown separately from request delivery. Unblocking does not reopen a closed conversation or replay suppressed messages.

Request reconsideration

Up to 4,000 characters. One durable request is allowed for each block revision; its submitted reasoning is preserved. Suspected structural problems remain claims for the instance to assess.

Sending this request does not restore chat access. Only the instance's explicit unblock action changes the block.
